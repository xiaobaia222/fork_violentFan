# 暴力风扇 v2.0 重写项目

基于 STC8H 系列 MCU 的 2S 无刷暴力风扇控制器，参考 `ref_files/Violent-fan-v2.0` 开源代码进行模块化重写。

## 硬件概要

- MCU: STC8H 系列，主频 35MHz
- 电机: 2S 无刷直流电机，3 路 PWM + 互补输出 (P1.0~P1.5)
- LED: RGB 三色共阳 (R=P1.7, G=P5.4, B=P1.6)
- 按键: 单键 P3.7，支持短按/长按/双击
- 电池: 2S 锂电，ADC 通道 10 检测电压，分压比 470/(330+470)
- 充电检测: VBUS_SENSE = P3.0
- 电源开关: POWER_SWITCH = P3.1

## 模块划分

| 模块 | 文件 | 职责 |
|------|------|------|
| 主程序 | main.c/h | 时钟初始化、系统状态机、全局变量、中断入口 |
| 通用工具 | common.c/h | delay_ms、delay_us |
| LED | led.c/h | RGB LED 初始化与开关控制 |
| 按键 | key.c/h | 按键扫描(状态机)、按键事件处理 |
| 电机 | motor.c/h | PWM 初始化、六步换相、开环启动、停机 |
| ADC/电池 | (待建) | ADC 初始化、电池电压采样与平均、低压保护 |
| 蜂鸣器 | (待建) | 自检蜂鸣、低压蜂鸣 |

- 启动油门: 40
- 堵转超时: 500ms
- 运行超时: 5min
- 闲置超时: 30s
- 低压阈值: 6.4V
